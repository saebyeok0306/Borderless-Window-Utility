# Borderless Window Utility

**한국어** | [English](README-en.md)

게임 창의 제목 표시줄과 테두리를 없애고, 정해 둔 크기와 위치로 자동 배치해 주는 Windows 트레이 프로그램입니다.

32:9(5120×1440) 같은 슈퍼 울트라와이드 모니터에서 게임을 QHD(2560×1440)로 화면 가운데에 띄우고 싶을 때 유용합니다.
21:9, 32:9, 4K 등 모니터 해상도와 상관없이 동작합니다.
전체 화면으로 실행하면 양옆이 검은 여백으로 채워지고, 창 모드로 실행하면 제목 표시줄 때문에 창 아래쪽이 화면 밖으로 밀려나는데,
이 프로그램은 게임 창을 테두리 없는 창으로 바꿔 원하는 자리에 딱 맞게 놓아 줍니다.

## 주요 기능

- **자동 적용**: 등록한 게임 창이 뜨면 몇 초 안에 테두리를 없애고 크기와 위치를 맞춥니다.
- **왼쪽 / 가운데 / 오른쪽 배치**: 모니터 해상도를 읽어 정한 쪽에 맞춰 놓습니다. (5120×1440에서 2560×1440 → 왼쪽 0, 가운데 1280, 오른쪽 2560)
  게임을 하는 중에도 트레이 메뉴에서 바로 바꿀 수 있습니다.
- **간편한 등록**: 트레이 아이콘의 창 목록에서 게임을 선택하고 버튼 하나로 등록합니다.
- **Windows 시작 시 자동 실행**
- **한국어 / 영어** 지원
- **설치 필요 없음**: 약 150KB짜리 exe 파일 하나로 동작합니다.

## 요구 사항

- Windows 10 (1903 이상) 또는 Windows 11
- .NET Framework 4.8 (위 Windows 버전에 기본으로 들어 있어 따로 설치할 필요가 없습니다)

## 설치

1. [Releases](../../releases)에서 `BorderlessWindowUtility.exe`를 내려받습니다.
2. 원하는 폴더에 두고 실행합니다. 작업 표시줄 오른쪽 알림 영역에 트레이 아이콘이 나타납니다.
3. 트레이 아이콘을 마우스 오른쪽 버튼으로 클릭하고 **Windows 시작 시 자동 실행**을 켜 두면 부팅할 때마다 자동으로 실행됩니다.

> 코드 서명이 되어 있지 않아 처음 실행할 때 Windows SmartScreen 경고가 나올 수 있습니다.
> **추가 정보 → 실행**을 누르면 됩니다.

## 사용 방법

1. 게임을 **창 모드**로 실행합니다. (전체 화면 모드에서는 창 위치를 바꿀 수 없습니다)
2. 트레이 아이콘을 더블클릭해 **창 목록**을 엽니다.
3. 목록에서 게임을 선택하면 이름과 프로세스가 자동으로 채워집니다. 크기와 배치(왼쪽/가운데/오른쪽)를 확인하고 **profiles.ini에 추가**를 누릅니다.
4. 몇 초 안에 게임 창에 적용됩니다. 다음부터는 게임을 켜기만 하면 자동으로 적용됩니다.

### 트레이 메뉴

| 메뉴 | 설명 |
|---|---|
| 창 목록 / 프로필 추가 | 열려 있는 창과 프로세스 이름을 보여 주고, 게임을 프로필로 등록합니다. (아이콘 더블클릭) |
| profiles.ini 편집 | 프로필 파일을 기본 편집기(보통 메모장)로 엽니다. 저장하면 바로 반영됩니다. |
| 로그 열기 | 적용 기록과 오류를 확인합니다. |
| 배치 | 실행 중인 게임을 왼쪽/가운데/오른쪽으로 바로 옮기고, 그 설정을 프로필에 저장합니다. (프로필에 `x`를 직접 적어 두었다면 지워집니다) |
| 언어 (Language) | 자동(시스템 언어), English, 한국어 중에서 고릅니다. |
| Windows 시작 시 자동 실행 | 로그인할 때 자동으로 실행합니다. |
| 자동 적용 일시 정지 | 자동 적용을 잠시 멈춥니다. |
| 종료 | 프로그램을 끝냅니다. |

프로그램이 이미 실행 중일 때 exe를 다시 실행하면 창 목록이 열립니다.

## 해상도별 동작

배치 위치는 실행할 때마다 모니터의 실제 해상도를 읽어 계산합니다.
왼쪽은 모니터 왼쪽 끝, 가운데는 `(모니터 너비 − 창 너비) ÷ 2`, 오른쪽은 `모니터 너비 − 창 너비`이고, 세로는 가운데에 맞춥니다.
창 목록에서 프로필을 추가할 때는 모니터 세로 해상도에 맞춘 16:9 크기를 기본값으로 제안합니다.

| 모니터 | 제안 크기 | 왼쪽 | 가운데 | 오른쪽 |
|---|---|---|---|---|
| 21:9 UWFHD 2560×1080 | 1920×1080 | 0, 0 | 320, 0 | 640, 0 |
| 21:9 WQHD 3440×1440 | 2560×1440 | 0, 0 | 440, 0 | 880, 0 |
| 32:9 DFHD 3840×1080 | 1920×1080 | 0, 0 | 960, 0 | 1920, 0 |
| 32:9 DQHD 5120×1440 | 2560×1440 | 0, 0 | 1280, 0 | 2560, 0 |
| 32:9 DUHD 7680×2160 | 3840×2160 | 0, 0 | 1920, 0 | 3840, 0 |
| 16:9 4K 3840×2160 | 3840×2160 | 0, 0 | 0, 0 | 0, 0 |

16:9 모니터에서는 창이 화면을 꽉 채우므로 배치와 상관없이 테두리 없는 전체 화면 창이 됩니다.

- **프로필 크기는 픽셀 값입니다.** 다른 해상도의 모니터로 바꿨다면 창 목록에서 프로필을 다시 등록하거나 `width`, `height`를 고쳐 주세요.
  예를 들어 2560×1440 프로필을 DUHD(7680×2160)에서 쓰면 화면 가운데에 작게 뜹니다.
- **화면 배율(DPI)과 상관없이** 실제 픽셀 기준으로 계산하므로, 150% 같은 배율을 써도 위치가 어긋나지 않습니다.
- **모니터가 여러 대일 때**는 기본적으로 주 모니터를 기준으로 배치합니다.
  울트라와이드 모니터가 주 모니터가 아니라면 프로필에 `monitor=window`를 넣어 게임이 열린 모니터를 기준으로 맞추세요.
- 창 크기를 바꿔도 내부 렌더링 해상도를 고정해 두는 게임은 화면이 늘어나 보일 수 있습니다. 이 경우 게임 설정에서 해상도를 창 크기와 같게 맞춰 주세요.

## 프로필 (profiles.ini)

프로필은 `%APPDATA%\BorderlessWindowUtility\profiles.ini`에 저장됩니다. 창 목록에서 등록해도 되고, 직접 편집해도 됩니다.

```ini
[EZ2ON]
process=ez2on.exe
width=2560
height=1440
align=center
```

| 항목 | 설명 | 기본값 |
|---|---|---|
| `[이름]` | 프로필 이름입니다. | |
| `process` | 게임 실행 파일 이름입니다. (작업 관리자 → 세부 정보에서 확인) | |
| `title` | 창 제목에 들어 있는 글자입니다. `process`와 함께 쓰면 둘 다 일치해야 합니다. | `process`가 없으면 프로필 이름 |
| `width`, `height` | 창 크기입니다. | |
| `align` | 가로 배치입니다. `left`(왼쪽), `center`(가운데), `right`(오른쪽) | `center` |
| `x`, `y` | 창 위치를 직접 정합니다. `x`를 적으면 `align`보다 우선하고, 비워 두면 `align`에 따라 놓습니다. `y`를 비워 두면 세로 가운데입니다. | 비움 |
| `monitor` | 배치 기준 모니터입니다. `primary`(주 모니터) 또는 `window`(게임이 열린 모니터) | `primary` |
| `delay` | 창이 뜬 뒤 적용하기까지 기다리는 시간(초)입니다. | `3` |
| `auto` | `false`로 하면 자동 적용에서 제외합니다. | `true` |

`;` 또는 `#`로 시작하는 줄은 주석입니다.

## 명령줄 옵션

```
BorderlessWindowUtility.exe --install              로그인할 때 자동 실행 (현재 사용자)
BorderlessWindowUtility.exe --install --elevated   관리자 권한으로 자동 실행 (관리자 터미널에서 실행)
BorderlessWindowUtility.exe --uninstall            자동 실행 해제
BorderlessWindowUtility.exe --window-list          창 목록만 열기
```

## 문제 해결

**적용이 안 돼요**
- 게임이 전체 화면 모드면 창 모드로 바꿔 주세요.
- 게임이 관리자 권한으로 실행된다면 이 프로그램도 관리자 권한이 필요합니다.
  관리자 터미널에서 `BorderlessWindowUtility.exe --install --elevated`를 실행한 뒤 다시 로그인하세요.
- 안티치트가 걸린 게임은 실행 파일 이름을 읽지 못할 수 있습니다. 이때는 `process` 대신 `title`(창 제목)로 등록하세요.
- 트레이 메뉴의 **로그 열기**에서 원인을 확인할 수 있습니다.

**안티치트에 걸리지 않나요?**
이 프로그램은 Windows가 창을 다룰 때 쓰는 기본 기능으로 창 테두리와 위치, 크기만 바꿉니다.
게임 메모리를 읽거나 쓰지 않고, 게임에 코드를 넣지 않고, 입력을 흉내 내지도 않습니다.
다만 모든 게임에서 문제가 없다고 보장할 수는 없으니, 걱정된다면 게임의 이용 약관이나 공식 안내를 확인해 주세요.

**성능에 영향이 있나요?**
1초에 한 번 열린 창 목록을 확인하는 정도라 체감할 수 있는 영향은 없습니다.

**프로그램을 지우려면?**
트레이 메뉴에서 **Windows 시작 시 자동 실행**을 끄고 종료한 뒤 exe 파일을 지우면 됩니다.
설정까지 지우려면 `%APPDATA%\BorderlessWindowUtility` 폴더도 삭제하세요.

## 직접 빌드하기

[.NET SDK](https://dotnet.microsoft.com/download) 8 이상을 설치하고 `build.bat`을 실행하면 `dist\BorderlessWindowUtility.exe`가 만들어집니다.
다시 빌드할 때는 먼저 트레이에서 프로그램을 종료하세요.

### CI / 릴리스

GitHub Actions(`.github/workflows/build.yml`)로 자동 빌드합니다.

- `main` 브랜치에 푸시하거나 PR을 올리면 exe를 빌드합니다. 결과물은 Actions 탭의 해당 실행 → **Artifacts**에서 받을 수 있습니다.
- `v1.0.0` 같은 버전 태그를 푸시하면 그 버전으로 빌드해 GitHub Release를 만들고 exe를 첨부합니다.

  ```
  git tag v1.0.0
  git push origin v1.0.0
  ```

  `v1.1.0-beta.1`처럼 뒤에 접미사가 붙은 태그는 프리릴리스로 게시됩니다.
